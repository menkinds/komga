# 2026-11-07 — 웹 UI 라이브러리 숨김(암호)·시리즈 커버 읽기 버튼, PR #6 머지, 포크 워크플로 재활성화 후 도커 빌드

- 목표/요청: Komelia의 라이브러리 숨김을 Komga 웹 UI에도 넣기(암호로 해제), 시리즈 커버에 읽기 버튼, PR·머지·빌드.
- 도구: Claude Code | Codex | Cursor
- 모델: claude-opus-5-5
- 토큰 사용량(komga·Komelia 작업을 함께 한 세션 전체): 응답 수 122 · 입력 259 · 캐시 생성 351,837 · 캐시 읽기 23,797,542 · 출력 57,291 · 합계 24,206,929 / 모델/토큰: 알 수 없음 (이 폴더와 맞는 세션 기록을 찾지 못함) / 모델/토큰: 알 수 없음 (이 폴더와 맞는 세션 기록을 찾지 못함)
- 핵심 프롬프트(원문):
  > Komga에서도 Komelia에 적용한 라이브러리 숨김 기능 추가. 저 점 세개 눌러서 숨길 수 있고, 숨김 해제하기 위해서는 설정한 암호가 필요하고 전체 라이브러리의 점세개 눌렀을때 해제 메뉴가 보이게.
  > 
  > Komga
  > 시리즈를 클릭해서 들어갔을때, 시리즈의 커버는 눌러도 아무 기능이 없는데,
  > 시리즈의 커버를 눌렀을때는 지금 읽고있는 그 시리즈의 진행중 책이나, 다음에 읽어야하는 걸 바로 읽을 수 잇게 빨간 동그라미 버튼 추가. (오른쪽 아래랑 같은 거)
  > Komelia도
  > 마찬가지 방식으로 작동되게
  > 
  > (중략) 둘다 피알 만들고 문제없으면 머지하고 빌드해줘
- 진행 내용: Komelia 구현(AdultLockState, RestrictedKomgaApi)을 읽고, Komga 웹 UI의 기존 pinned/unpinned 구조에 숨김을 얹음. 암호는 사용자 client setting에 salt+SHA-256(순수 JS). 검색은 libraryId isNot 조건. 시리즈 커버는 ItemCard에 readTo prop을 더하고 진행 중→첫 안 읽음→첫 권 순서로 대상 책을 찾음. eslint·번들 빌드 확인 후 PR #6 머지, 포크 워크플로 재활성화 뒤 docker-publish 성공.
- 막힌 점 · 실패와 원인: webpack 타입체커가 8GB에서도 메모리 부족(.vue 타입 미검사). 머지 push에 빌드가 안 돌았는데, GitHub가 포크 워크플로를 꺼 둔 것이 원인이었음(Settings 허용과 별개, Actions 탭 re-enable 버튼으로 해결). 재시도 루프가 겹쳐 빌드 2건이 생겨 사용자가 1건 취소.
