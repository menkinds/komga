# 2026-11-28 — 웹 리더가 책을 열 때 띄우던 읽기 방향 알림 제거, PR #10 머지

- 목표/요청: 책을 열 때마다 뜨는 읽기 방식 팝업 제거(웹 리더 쪽).
- 도구: Claude Code (클라우드 세션)
- 모델: claude-opus-5-5
- 토큰 사용량: 응답 수 170 · 입력 377 · 캐시 생성 981,160 · 캐시 읽기 37,808,413 · 출력 91,835 · 합계 38,881,785 (같은 대화 전체 누적값, 앞선 komga 11-26·11-27 기록 포함)
- 핵심 프롬프트(원문):
  > (리더 화면 스크린샷) 새로 읽기 시작할때마다 저 팝업 안 뜨게 하고싶늠
  > 머지해 다
- 진행 내용:
  1. 웹 리더가 책을 열 때 읽기 방향 알림을 띄우는 호출 두 곳을 지움. 직접 방향을 바꿀 때의 알림은 유지.
  2. 나중에 스크린샷의 팝업은 휴대폰 앱(Komelia) 것으로 밝혀졌지만, 웹도 같은 동작이라 사용자 결정으로 함께 머지.
  3. 이미지 자동 빌드 성공.
- 막힌 점 · 실패와 원인:
  - 팝업 출처를 확인하지 않고 추정해서 먼저 웹 쪽을 고침.
  - 웹 빌드의 타입 검사 단계가 메모리 부족으로 죽음(예전부터 있던 문제). 번들은 완성됨.
